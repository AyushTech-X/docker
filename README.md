## 1. Five DevOps Concepts (Any 5)

### **1. Continuous Integration (CI)**
The practice of frequently merging code changes into a shared repository and automatically testing them to ensure the application works as expected.

### **2. Continuous Delivery (CD)**
An extension of CI where every change is automatically tested and prepared for deployment to production with minimal manual steps.

### **3. Version Control**
Using Git or similar tools to track code changes, collaborate with others, and maintain history.

### **4. Infrastructure as Code (IaC)**
Managing and provisioning infrastructure through code (e.g., Dockerfiles, Terraform) rather than manual configuration.

### **5. Containerization**
Packaging applications and dependencies into portable containers (e.g., Docker), so they run consistently across environments.
